河北对口升学计算机技能测试练习系统 1.0.0
================================================

【这是什么】

一个用于河北对口升学计算机类考试备考的练习工具。
核心功能是提交代码即自动判分，判题用的编译与运行参数按省考场口径配置，
避免出现"在家能做、考场做不出"的情况。

【关于 Windows 提示"已保护你的电脑"】

本软件是开源软件，源代码就在本页面（Source code），可自行查看与核对。
Windows 会对"没有数字签名的程序"弹出蓝色警告窗，这是它的常规行为，
不代表本软件有病毒或问题。

如果你看到这个提示，请点击「更多信息」→「仍要运行」。

如需自行核对，可按以下方式验证文件完整性：

  1. 打开本软件的安装包
  2. 用任意校验工具计算其 SHA256 值
