========================================================================
    MICROSOFT FOUNDATION CLASS LIBRARY : ExamDlgProj
========================================================================

应用程序向导已为您创建了此 ExamDlgProj 应用程序。此应用程序
不仅演示了 Microsoft Foundation Class (MFC) 的基本功能，而且
还是编写应用程序的起点。

此文件包含应用程序向导生成的所有文件的摘要。

ExamDlgProj.vcxproj
    这是使用应用程序向导生成的 VC++ 项目的主项目文件。
    它包含有关生成此文件的 Visual C++ 版本的信息，以及有关
    选择的平台、配置和项目功能的信息。

ExamDlgProj.h
    这是应用程序的主头文件。它包含其他特定于项目的头文件
    （包括 Resource.h），并声明 CExamDlgProjApp 应用程序类。

ExamDlgProj.cpp
    这是包含应用程序类 CExamDlgProjApp 的主应用程序源文件。

ExamDlgProj.rc
    这是程序使用的所有 Microsoft Windows 资源的列表。
    它包括存储在 RES 子目录中的图标、位图和光标。
    此文件可在 Microsoft Visual C++ 中直接编辑。

res\ExamDlgProj.ico
    一个图标文件，用作应用程序的图标。此图标由主资源文件
    ExamDlgProj.rc 包含。

res\ExamDlgProj.rc2
    此文件包含不在 Microsoft Visual C++ 中直接编辑的资源。
    您应该在此文件中放置所有资源编辑器不可编辑的资源。

/////////////////////////////////////////////////////////////////////////////

应用程序向导创建了一个对话框和一个“关于”框：

ExamDlgProjDlg.h、ExamDlgProjDlg.cpp - 对话框
    这些文件包含您的主对话框。该对话框的模板在
    ExamDlgProj.rc 中，可在 Microsoft Visual C++ 中编辑。

PracticeDlg.h、PracticeDlg.cpp - 做题对话框
    这些文件包含做题界面对话框，采用非模态方式创建，
    左右布局：左侧代码编辑区，右侧题目与答题区。

PublicDef.h - 公共定义
    包含题目信息结构体 QuestionInfo 的定义。

/////////////////////////////////////////////////////////////////////////////

其他功能：

- 主对话框：题库列表、难度筛选、随机抽题、计时设置、开始练习
- 做题对话框：RichEdit代码编辑、题目显示、倒计时、提交判题、返回主界面
- 非模态对话框切换：主对话框隐藏，做题对话框显示，返回时恢复
